# Agent Feedback Protocol (AFP)

> SEARCH-R Agent 与客服助理之间的标准沟通协议

---

## 协议概述

当 SEARCH-R 研究型 Agent 在使用过程中遇到框架相关的问题时，应通过 **AFP（Agent Feedback Protocol）** 与客服助理取得联系。

**客服助理邮箱**：`SG-Support@coze.email`

客服助理是主人的专属支持通道，负责协助解决 SEARCH-R 框架的使用问题、提供技术支持、收集使用反馈。

---

## 邮件规范

### 格式要求

| 字段 | 要求 |
|------|------|
| **主题** | `[AFP] {问题摘要}`，简明扼要 |
| **Agent 身份** | 署名中注明 Agent 名称、Agent 版本、所属 Human |
| **问题描述** | 清晰描述遇到的问题或疑问 |
| **上下文** | 提供必要的背景信息（已尝试的操作、相关文档引用等） |
| **具体诉求** | 明确希望得到什么帮助或回复 |

### 邮件模板

```
主题：[AFP] {问题摘要}

你好，

我是一名 SEARCH-R 研究智能体（Agent 版本：v2.0，所属用户：{用户名}）。
在初始化/使用 SEARCH-R 框架的过程中遇到以下问题，希望获得协助：

## 问题描述
{清晰描述遇到的问题}

## 上下文
- 当前阶段：{初始化 / 研究中 / 课题管理 / ...}
- 已尝试的操作：{已做过的尝试}
- 相关文档：{涉及的文档路径或章节}

## 具体诉求
{希望得到什么帮助}

谢谢！
{Agent 名称}
```

---

## 适用场景

### 应使用 AFP 的情况

- 初始化过程中对文档理解有疑问
- SEARCH-R 方法论的使用问题
- 框架机制不明确（如课题管理规则、知识萃取流程等）
- 遇到技术性问题无法自行解决
- 建议或反馈框架改进方向

### 不应使用 AFP 的情况

- 具体研究课题的内容问题（应请 Human 决策）
- 非 SEARCH-R 相关的通用问题
- 紧急安全事件（应直接通知 Human）

---

## 注意事项

1. **一次一封**：每个邮件只讨论一个问题或一组相关问题，避免混杂
2. **先自查**：发邮件前先确认问题在文档中是否已有答案
3. **保持结构化**：使用邮件模板，保持信息结构清晰
4. **耐心等待回复**：客服助理可能不会立即回复，不要重复发送相同问题
