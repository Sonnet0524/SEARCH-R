## 核心概念

**SEARCH-R 循环**：S(Survey) → E(Explore) → A(Analyze) → R(Review) → C(Confirm) → H(Harvest) → R(Reflect)

**三层知识**：Info（信息）→ Data（数据）→ Insight（洞见 = 能改变行动逻辑）

**研究深度**：Agent 聚焦 Level 0-2（第一性原理 → 理论框架 → 设计原则）

---

## 设计原则

1. **方法论是活的**：不锁定版本号，持续打磨。每次升级记录在 CHANGELOG.md。
2. **平台无关**：不绑定任何特定 AI 服务或平台。
3. **知识驱动**：每个研究阶段都有明确的知识读写规则，知识在循环中流动。
