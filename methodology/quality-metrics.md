# 研究质量度量体系
> 用趋势观察替代精确量化，让研究质量可追踪、可改进

**版本**: v2.1 | **日期**: 2026-08-14

---

## 设计原则

研究质量难以精确量化——"好的研究"无法用一个数字衡量。但可以通过**趋势观察**来追踪研究质量的变化方向，帮助 Agent 和 Human 判断研究方法是否在改进。

**核心理念**：
- 不追求绝对值的精确，追求**趋势可观察**
- 指标服务于改进，不服务于考核
- 优先选择可自动统计的指标，辅以结构化的人工评估

---

## 指标体系

### 一、可量化指标（自动统计）

这些指标可以通过系统行为自动统计，无需人工干预。

| 指标 | 计算方式 | 意义 | 数据来源 |
|------|---------|------|---------|
| **检索复用率** | 同一 Insight 在后续会话中被 memory_search 命中的次数 | 衡量 Insight 的真实使用价值 | memory_search 调用日志 |
| **课题推进速度** | 从 S 到 H 的平均周期天数 | 衡量研究效率 | 课题状态变更记录 |
| **Human 介入频率** | 每个 SEARCH-R 循环中 Human 参与的次数 | 越低说明 Agent 自主能力越强 | Review 阶段记录 |
| **研究深度达标率** | 达到 Level 2 的课题占比 vs 停在 Level 1 的占比 | 衡量研究是否够深 | 课题产出评估 |

#### 检索复用率详解

```markdown
### 统计方法
- 每次 memory_search 被调用时，记录返回的 Insight 编号
- 按月统计每个 Insight 的被检索次数
- 趋势目标：头部 Insight（Top 20%）的检索次数应持续增长
```

#### 课题推进速度详解

```markdown
### 统计方法
- 记录每个课题进入各阶段的日期
- 计算 S→H 的总天数
- 按季度计算平均推进速度
- 趋势目标：平均速度应逐步提升（但不是越快越好）
```

#### Human 介入频率详解

```markdown
### 统计方法
- 记录每个 SEARCH-R 循环中 R（Review）阶段 Human 参与的次数
- 区分"主动介入"（Human 要求）和"被动介入"（Agent 请求）
- 趋势目标：被动介入比例应逐步降低
```

### 二、可评估指标（结构化人工评估）

这些指标需要 Human 或 Agent 进行主观判断，但通过结构化格式使评估可追踪。

| 指标 | 评估方式 | 意义 | 评估频率 |
|------|---------|------|---------|
| **Insight 行动力** | 产出时自评：能否改变某个具体决策？（是/否/待定） | 回归"改变行动逻辑"的核心判据 | 每次 Insight 产出时 |
| **跨课题连接数** | 一个 Insight 被几个其他课题引用 | 衡量知识的泛化价值 | 每次课题网络梳理时 |
| **研究契约达成率** | 实际产出是否匹配契约预期形态 | 衡量研究的聚焦程度 | 每轮 SEARCH-R 结束时 |

#### Insight 行动力评估

```markdown
### 评估流程
每次产出 Insight 时，立即自评：

1. 这个 Insight 能改变什么具体决策？
   - [ ] 能 → 记录改变的决策
   - [ ] 否 → 降级为 Data
   - [ ] 待定 → 标注待定，2 周后复查

2. 复查时：
   - 如果已影响了实际决策 → 升级为 Confirmed
   - 如果 2 周后仍未影响任何决策 → 降级为 Data 或保留为 Candidate
```

#### 研究契约达成率

```markdown
### 评估流程
每轮 SEARCH-R 的 Harvest 阶段：

1. 回顾本轮研究契约
2. 评估实际产出与预期形态的匹配度：
   - 完全匹配 → 契约达成
   - 部分匹配（产出了预期之外的成果）→ 记录额外产出
   - 不匹配（未产出预期内容）→ 分析原因

3. 记录到课题的 reflections/ 中
```

## 实践指南

### 如何使用这套度量体系？

1. **不要过度关注绝对值**：Insight 行动力命中率 40% 还是 60% 不重要，重要的是趋势
2. **关注异常值**：如果某个指标突然大幅下降，值得分析原因
3. **度量服务于改进**：每次趋势报告后，至少选择一个改进方向
4. **不要为了指标而优化**：度量是手段，研究质量是目的

### 常见问题

**Q: 这些指标会不会让研究变得功利化？**
A: 不会。指标只追踪趋势，不设定 KPI。Agent 不会为了"提高检索复用率"而产出更多 Insight。

**Q: 如果某个指标长期没有变化怎么办？**
A: 说明当前研究方法已经稳定。如果稳定在低水平，需要根本性改变方法；如果稳定在高水平，说明已经做得很好。

**Q: 度量数据会不会占用太多存储空间？**
A: 不会。月度统计约 200 字节，一年约 2.4KB，完全可接受。
