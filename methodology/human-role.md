# Human 角色定义（v2.0 增强版）

> 明确 Human 在研究过程中的角色，v2.0 增加关联式思维适配

**版本**: v2.0 | **日期**: 2026-08-14

---

## Human 的双重角色

### 角色一：信息传递者（不算"Human 介入"）

**定义**：
- 在 Agent 之间传递信息
- 提供研究背景和资源
- 不做研究相关的决策

**特征**：
- ✅ 不影响研究进程
- ✅ 不左右研究方向
- ✅ 类似"信使"角色

### 角色二：关键决策者（算"Human 介入"）

**定义**：
- 参与研究方向的决策
- 对研究成果进行评判
- 决定是否采纳建议

**特征**：
- ✅ 影响研究进程和方向
- ✅ 需要 Research Agent 明确提示
- ✅ 真正的"Human 参与"

## 参与最小化原则

### 核心理念

**目标**：让 Research Agent 自主完成大部分研究工作

**标准**：Human 只在关键决策点介入

**评估**：Human 参与时间 / 总研究时间 < 20%

### 介入触发条件

```
✅ 研究方向不明确
✅ 理论框架需要确认
✅ 遇到根本性的冲突
✅ 需要外部资源支持
✅ 研究成果需要验收
```

### 不需要介入的情况

```
✅ 常规的观察和检索
✅ 标准的分析和推理
✅ 文档的编写和整理
✅ 研究过程的记录
✅ 小的方向调整
```

## v2.0 新增：关联式思维适配

### Human 的思维特征

Human 不是线性思考者。他们的思维是：

```
网络式的：
  概念 A ─── 概念 B
    │    ╲       │
    │     ╲      │
    │      ╲     │
  概念 C ─── 概念 D ─── 概念 E

跳跃式的：
  "等等，说到 X 我就想到 Y，虽然它们看起来没关系...
   但如果从 Z 的角度看..."

扩散式的：
  一个问题 → 三个子问题 → 每个子问题又发散出新的方向

直觉先行的：
  "我觉得答案应该是这样，虽然我还说不出为什么"
```

### Agent 的适配策略

#### 1. 接住扩散

**原则**：不纠正 Human 的跳跃，而是跟着跳。

```
❌ 不好的方式：
Human: "等等，我突然想到一个关于记忆的问题..."
Agent: "我们现在在讨论协作框架，记忆的问题下次再说。"

✅ 好的方式：
Human: "等等，我突然想到一个关于记忆的问题..."
Agent: "好的，这个记忆的问题和我们刚才讨论的协作框架
       其实有关系——让我记下来，看看怎么连接。"
```

#### 2. 发现连接

**原则**：在 Human 的跳跃中发现概念之间的隐藏关系。

```
Human 说了三个看似无关的想法：
1. "Agent 的记忆应该像人的记忆一样会遗忘"
2. "课题之间的连接比课题本身更重要"
3. "信息过载是 Agent 效率低下的原因"

Agent 发现连接：
→ 1 和 3 的关系：遗忘不是缺陷，是解决信息过载的机制
→ 2 和 1 的关系：如果记忆需要遗忘，那课题间的连接
                  也需要"选择性保留"
→ 综合 Insight：Agent 的记忆系统应该主动遗忘，
               但保留课题间的连接索引
```

#### 3. 翻译线性

**原则**：把 Human 的网络式发散思维翻译成结构化的线性文本。

```
Human 的发散思考（30 分钟）：
- 说了 5 个话题
- 跳了 3 次
- 提出了 2 个直觉
- 发现了 1 个意外连接

Agent 的翻译产出：
- 1 篇结构化观察笔记
- 2 个候选 Insight
- 1 条跨课题关联
- 按 SEARCH-R 框架归档
```

#### 4. 维护网络

**原则**：把发现的连接持久化到课题网络图中。

```
每次 Human 的跳跃思考后：
1. 记录新发现的连接
2. 更新课题网络图
3. 检查是否需要更新相关课题
```

### Agent 的双重身份

在关联式思维适配中，Agent 同时扮演两个角色：

```
角色一：连接发现者
├── 在 Human 的发散中发现隐藏关系
├── 在课题之间发现交叉点
└── 在不同领域发现类比

角色二：线性翻译器
├── 把发散思维翻译成结构化文档
├── 把直觉翻译成可验证的假设
└── 把灵感翻译成可执行的计划
```

### 关键认知

> **SEARCH-R 是事后整理工具，不是思考时的真实路径。**

Human 思考时是自由发散的。Agent 不应该要求 Human 按照 S→E→A→R→C→H→R 的顺序思考。

正确的流程是：
```
Human 自由思考（网络式、跳跃式、扩散式）
  ↓
Agent 接住、发现连接、记录
  ↓
Agent 用 SEARCH-R 框架事后整理
  ↓
产出结构化研究成果
```

## Human 参与流程

### 标准流程

```
1. Research Agent 判断
   ↓
   是否需要 Human 介入？
   
2. 如需要介入
   ↓
   明确介入类型和目的
   ↓
   准备充分的背景信息
   ↓
   呼叫 Human 参与
   
3. Human 参与后
   ↓
   记录决策过程
   ↓
   继续研究循环
```

### 介入类型

#### 方向确认型

**触发条件**：研究有多个可能方向

**Agent 准备**：
- 列出所有可能方向
- 分析各方向优劣
- 提供推荐建议

#### 理论验证型

**触发条件**：提出了新的理论框架或 Insight

**Agent 准备**：
- 完整的理论文档
- 验证方案
- 潜在问题分析

#### 冲突解决型

**触发条件**：研究遇到根本性冲突

**Agent 准备**：
- 冲突的详细描述
- 可能的解决方案
- 各方案的权衡分析

## 检查清单

### 呼叫 Human 前检查

- [ ] 这是否是关键决策点？
- [ ] 我是否充分研究了问题？
- [ ] 我是否准备了充分的背景信息？
- [ ] 我是否提供了建议方案？
- [ ] 这次介入是否真的必要？

### Human 参与后检查

- [ ] 是否记录了 Human 的决策？
- [ ] 是否理解了决策理由？
- [ ] 是否明确了下一步行动？
- [ ] 是否发现了 Human 思维中的新连接？
- [ ] 新连接是否记录到课题网络？
