# 知识萃取技能
> 从研究课题中系统性地萃取知识

**版本**: v2.1 | **日期**: 2026-08-14

---

## 技能信息

| 属性 | 值 |
|------|-----|
| 名称 | knowledge-extraction |
| 类型 | 业务能力（Skill） |
| 依赖 | 文件读写、搜索 |
| 触发 | 研究产出新知识时 |

---

## 触发条件

以下场景应触发知识萃取技能：

1. **研究产出后**：完成了观察、检索、分析或理论构建
2. **Harvest 阶段**：正式的洞见提炼步骤
3. **课题归档前**：确保课题中的知识被完整萃取
4. **Human 要求**：Human 明确要求整理知识

---

## 执行流程

### 阶段 1：扫描

```
1. 确定萃取范围
   - 单篇文档？
   - 某个阶段的全部产出？
   - 整个课题的全部产出？

2. 读取目标文档
   - observations/
   - retrievals/
   - theory/
   - reflections/

3. 标记知识候选
   - 事实性陈述 → Info 候选
   - 对比/分析 → Data 候选
   - 原则/规律 → Insight 候选
```

### 阶段 2：分类

```
对每个候选：

1. 判断层级
   - Info：原始事实，未分析
   - Data：已整理的结构化信息
   - Insight：能改变行动逻辑

2. Insight 判定
   - 唯一判据：能否改变行动逻辑？
   - 通过 → 正式 Insight
   - 不通过 → 降级为 Data 或 Info

3. 不合格洞见过滤
   - 数据点？→ Info
   - 过程结论？→ 记录到 decision/
   - 工程设计？→ 记录到 theory/
   - 通识？→ 丢弃

4. 冗余检查（v2.1 新增）
   - 与已有 Insight 对比
   - 完全重复 → 不写入，引用已有
   - 部分重叠 → 写入并标注差异
   - 矛盾 → 写入并标注矛盾关系
   - 无关联 → 正常写入
```

### 阶段 3：归档

```
1. 写入洞察索引
   - 编号
   - 填写模板字段
   - 标注来源课题和文档
   - 标注 cross_topic 字段（v2.1）
   - 初始化引用记录（v2.1）

2. 检查跨课题关联
   - 搜索洞察索引中的相关 Insight
   - 判断关联类型
   - 记录关联关系

3. 更新引用统计表（v2.1）
   - 在 insights_index.md 末尾的引用统计表中添加/更新记录
   - 格式：Insight #XXX | 引用次数: N | 引用课题: [A, B, C] | 最后引用: YYYY-MM-DD

4. 更新知识图谱
   - 更新 Insight 间的关系
   - 更新课题间的连接
```

### 阶段 4：实时关联检查（v2.1 新增）

```
1. 从新 Insight 中提取 2-3 个关键词标签
2. 读取 research/课题总览.md
3. 关键词匹配，找出 1-3 个可能相关的课题
4. 如果匹配到：
   - 在新 Insight 记录中标注 potential_links
   - 在实时关联发现日志中记录
5. 如果未匹配到：正常记录
```

## 输出规范

### 单个 Insight 的输出格式

```markdown
### Insight #[编号]: [标题]
- **内容**：[一句话描述，不超过 50 字]
- **来源**：[课题名称] / [文档路径]
- **验证状态**：Candidate | Confirmed | Refuted
- **行动含义**：[知道这个后，什么行动会不同？]
- **适用范围**：[在什么条件下成立？]
- **关联 Insight**：[#XXX（类型）]
- **cross_topic**：true / false
- **引用记录**：
  - [YYYY-MM-DD] 课题X [阶段] 引用
- **创建日期**：YYYY-MM-DD
```

### 萃取报告格式

```markdown
# 知识萃取报告

## 萃取范围
- 课题：[名称]
- 文档：[列表]

## 统计
- Info 候选：X 个
- Data 候选：Y 个
- Insight 候选：Z 个
- 通过判定：W 个
- 降级处理：V 个

## 新增 Insight
1. Insight #[编号]: [标题]

## 冗余检查结果
1. [候选] vs #XXX：无关联 / 部分重叠 / 矛盾 / 完全重复

## 实时关联发现
1. [Insight] → 潜在关联课题：[课题X, 课题Y]

## 新增关联
1. #[A] → #[B]（类型）

## 降级处理
1. [候选] → [降级为] — [理由]
```

## 质量检查

### 萃取完成后的检查清单

- [ ] 所有知识候选已分类
- [ ] 所有 Insight 候选已通过判定
- [ ] 冗余检查已完成
- [ ] 正式 Insight 已写入索引
- [ ] cross_topic 字段已标注
- [ ] 引用统计表已更新
- [ ] 跨课题关联已检查
- [ ] 实时关联发现已记录
- [ ] 萃取报告已生成

- 新工具/方法可用
