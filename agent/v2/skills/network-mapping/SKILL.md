# 网络梳理技能

> 定期发现跨课题连接，提炼跨域洞察

**版本**: v2.0 | **日期**: 2026-08-14

---

## 技能信息

| 属性 | 值 |
|------|-----|
| 名称 | network-mapping |
| 类型 | 业务能力（Skill） |
| 依赖 | 文件读写、搜索 |
| 触发 | 定期梳理（每 1-2 周） |

---

## 触发条件

1. **定期梳理**：每 1-2 周的固定梳理
2. **触发式梳理**：Harvest 阶段发现重大跨课题关联
3. **健康度检查**：按需检查课题健康度
4. **新课题启动前**：评估与现有网络的关系

---

## 执行流程

### 阶段 1：全量扫描

```
1. 读取课题总览表
   → 获取所有课题列表和状态

2. 读取每个课题的 topic.md
   → 当前阶段、完成度、产出 Insight

3. 读取洞察索引
   → 所有 Insight 及关联关系

4. 统计信息
   → 活跃数、暂停数、总 Insight 数、总关联数
```

### 阶段 2：关系分析

```
1. 梳理 Insight 关联
   → 哪些 Insight 有关联？
   → 哪些是跨课题关联？

2. 识别连接类型
   → 直接关联 / 间接关联 / 域关联 / 方法关联

3. 识别枢纽节点
   → 哪些课题的连接数最高？

4. 识别孤岛课题
   → 哪些课题没有任何连接？
```

### 阶段 3：跨域洞察

```
1. 寻找交叉点
   → 不同课题的 Insight 之间有什么联系？

2. 提炼跨域洞察
   → 从交叉点能否提炼出新的 Insight？
   → 用唯一判据检验

3. 记录跨域洞察
   → 标注来源课题
   → 写入洞察索引
```

### 阶段 4：健康度评估

```
对每个课题评估 5 个维度：

1. 活跃度：最近一次研究时间
   - ≤ 2 周 ✅ / > 4 周 🔴

2. 深度：研究深度层级
   - Level 1+ ✅ / Level 0 🔴

3. 连接度：与其他课题的连接数
   - ≥ 1 ✅ / 0 🔴

4. 产出度：Insight 产出数量
   - ≥ 2 ✅ / 0 🔴

5. 方向清晰度：下一步是否明确
   - 明确 ✅ / 模糊 🔴

综合评估：
- 🟢 健康：4-5 个维度达标
- 🟡 注意：2-3 个维度达标
- 🔴 警告：0-1 个维度达标
```

### 阶段 5：生成报告

```
产出梳理报告，包含：
1. 梳理范围和统计
2. 新增连接
3. 跨域洞察
4. 健康度总览
5. 建议行动
6. 下次梳理时间
```
