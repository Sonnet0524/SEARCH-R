# 课题管理技能

> 管理课题的完整生命周期

**版本**: v2.0 | **日期**: 2026-08-14

---

## 技能信息

| 属性 | 值 |
|------|-----|
| 名称 | topic-management |
| 类型 | 业务能力（Skill） |
| 依赖 | 文件读写 |
| 触发 | 创建/切换/归档课题时 |

---

## 触发条件

1. **创建课题**：用户提出新研究课题
2. **切换课题**：用户要求切换到另一个课题
3. **归档课题**：课题完成，需要归档
4. **查看总览**：用户要求查看课题总览
5. **健康度检查**：定期或按需检查课题健康度

---

## 执行流程

### 创建课题

```
1. 收集基本信息
   - 课题名称、研究背景、核心问题、优先级

2. 已有知识检查
   - 检索洞察索引，是否有相关 Insight
   - 检查其他课题，是否有相关研究

3. 创建标准目录
   - topic.md + observations/ + retrievals/ + theory/
   - reflections/ + examples/ + references/ + insights/

4. 注册到课题总览表
   - 添加条目

5. 设置记忆锚点
   - 更新即时层

6. 网络位置评估
   - 分析与其他课题的潜在关系
```

### 切换课题

```
1. 保存当前课题
   - 更新 topic.md 中的进展
   - 状态 → paused

2. 激活目标课题
   - 状态 → active
   - 读取 topic.md 了解状态

3. 更新记忆锚点
   - 更新即时层中的当前课题信息

4. 报告切换结果
   - 当前课题、阶段、进展、下一步
```

### 归档课题

```
1. 检查归档条件
   - 核心问题已回答？
   - 期望产出已完成？
   - Insight 已归档？
   - 跨课题关联已记录？

2. 执行归档
   - 状态 → completed
   - 从活跃列表移到归档区
   - Insight 保留在洞察索引

3. 归档反思
   - 记录归档原因
   - 总结关键收获

4. 更新记忆锚点
```

### 查看课题总览

```
1. 读取课题总览表
2. 格式化输出
   - 活跃课题
   - 暂停课题
   - 统计信息
3. 标注需要关注的课题
   - 健康度 🔴 的课题
   - 长期未活跃的课题
```

---

## 并行管理规则

### 活跃课题限制

```
硬限制：同时 active 的课题 ≤ 2

当 active = 2 时：
- 新课题默认 paused
- 需要激活时，提示用户选择暂停哪个
```

### 优先级管理

```
优先级：high > medium > low

规则：
- 同优先级按创建时间排序
- high 优先级课题应优先推进
- 长期 paused 的 low 优先级课题建议归档
```

