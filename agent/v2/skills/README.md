## 技能详解

### 知识萃取技能

**文件**：[knowledge-extraction/SKILL.md](knowledge-extraction/SKILL.md)

**用途**：从研究课题中系统性地萃取知识，按 Info/Data/Insight 三层分类。

**触发条件**：
- 研究产出新的知识候选
- Harvest 阶段的洞见提炼
- 课题归档前的知识萃取

**核心能力**：
- 识别知识候选
- 三层分类（Info/Data/Insight）
- Insight 判定（唯一判据）
- 跨课题关联检查

---

### 课题管理技能

**文件**：[topic-management/SKILL.md](topic-management/SKILL.md)

**用途**：管理课题的完整生命周期，从创建到归档。

**触发条件**：
- 创建新课题
- 切换课题
- 归档课题
- 查看课题总览

**核心能力**：
- 课题初始化（标准目录 + 模板）
- 状态管理（active/paused/completed）
- 并行管理（≤2 活跃课题）
- 课题总览表维护

---

### 网络梳理技能

**文件**：[network-mapping/SKILL.md](network-mapping/SKILL.md)

**用途**：定期对全部课题进行网络化梳理，发现跨课题连接。

**触发条件**：
- 定期梳理（每 1-2 周）
- Harvest 后发现重大跨课题关联
- 需要评估课题健康度

**核心能力**：
- 全量课题扫描
- 关系分析
- 跨域洞察提炼
- 健康度评估
- 网络图生成

## Skills vs Tools

```
Skills（业务能力）
├── 方法论层面的能力
├── 定义"做什么"和"怎么做"
└── 可调用 Tools 来执行

Tools（底层工具）
├── 执行层面的工具
├── 定义"具体操作"
└── 被 Skills 调用
```

**示例**：
```
知识萃取（Skill）
├── 调用 文件读写（Tool）→ 更新洞察索引
├── 调用 搜索（Tool）→ 检查跨课题关联
└── 调用 文档生成（Tool）→ 生成梳理报告
```

## 技能加载方式

### 按需加载

技能不是一次性全部加载，而是根据当前任务按需加载：

```
任务类型 → 匹配技能 → 加载 SKILL.md → 按指引执行
```

### 技能组合

复杂任务可以同时加载多个技能：

```
示例：Harvest 阶段的洞见提炼
├── 加载 知识萃取技能 → 提炼 Insight
├── 加载 课题管理技能 → 更新课题状态
└── 加载 网络梳理技能 → 检查跨课题关联
```
