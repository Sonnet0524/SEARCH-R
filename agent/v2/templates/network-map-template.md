## 网络图模板

```markdown
# 课题网络图 YYYY-MM-DD

## 梳理信息

| 属性 | 值 |
|------|-----|
| 梳理日期 | YYYY-MM-DD |
| 扫描课题数 | X |

| 暂停课题 | Z |
| 总 Insight 数 | W |
| 跨课题连接数 | N |

## 课题节点

### [课题 A] [🟢/🟡/🔴]
- 阶段：[阶段]（[完成度]%）
- Insight：[编号列表]
- 连接数：[N]
- 健康度：
  - 活跃度：[✅/🔴]
  - 深度：[✅/🔴]
  - 连接度：[✅/🔴]
  - 产出度：[✅/🔴]
  - 方向：[✅/🔴]

### [课题 B] [🟢/🟡/🔴]
...

## 课题连接

### 新增连接
- [课题 A] ──**补充**──→ [课题 B]
  - Insight #XXX 补充了 Insight #YYY
  - 发现日期：YYYY-MM-DD

### 已有连接
- [课题 A] ──**增强**──→ [课题 C]
  - Insight #XXX 增强了 Insight #ZZZ

## 跨域洞察

### [跨域洞察标题]
- **来源交叉**：[课题 A] × [课题 B]
- **内容**：[一句话描述]
- **行动含义**：[什么行动会不同]
- **状态**：Candidate / Confirmed

## 网络拓扑

```
[课题 A] ───→ [课题 B]
   │              │
   │              │
   ↓              ↓
[课题 C] ←─── [课题 D]

图例：───→ 直接关联  - - → 间接关联

## 填写示例

```markdown
# 课题网络图 2026-08-14

## 梳理信息

| 属性 | 值 |
|------|-----|
| 梳理日期 | 2026-08-14 |
| 扫描课题数 | 4 |
| 活跃课题 | 2 |
| 暂停课题 | 1 |
| 总 Insight 数 | 15 |
| 跨课题连接数 | 6 |

## 课题节点

### Agent 记忆系统 [🟢]
- 阶段：Analyze（60%）
- Insight：#012, #013, #015
- 连接数：3
- 健康度：✅ ✅ ✅ ✅ ✅

### SEARCH-R 方法论 [🟢]
- 阶段：Harvest（80%）
- Insight：#001, #003, #005, #007, #010
- 连接数：3
- 健康度：✅ ✅ ✅ ✅ ✅

### 上下文管理策略 [🟡]
- 阶段：paused
- Insight：#008
- 连接数：1
- 健康度：🔴 ✅ 🟡 🟡 ✅

## 课题连接

### 新增连接
- [Agent 记忆系统] ──**补充**──→ [上下文管理策略]
  - Insight #015（记忆分层原则）补充了 Insight #008（信息过载问题）

### 已有连接
- [SEARCH-R 方法论] ──**方法关联**──→ [Agent 记忆系统]
  - 使用相同的质量门控框架

## 跨域洞察

### 分层架构的核心挑战在层间同步
- **来源交叉**：Agent 记忆系统 × 上下文管理策略
- **内容**：分层架构的挑战不在分层本身，而在层间的同步策略
- **行动含义**：设计分层系统时，应将 70% 的精力放在同步策略上
- **状态**：Candidate

## 网络拓扑

```
[Agent 记忆系统] ───→ [SEARCH-R 方法论]
       │                      │
       │                      │
       ↓                      ↓
[上下文管理策略]        [质量门控机制]

图例：───→ 直接关联
```

## 健康度总览

| 课题 | 活跃度 | 深度 | 连接度 | 产出度 | 方向 | 综合 |
|------|--------|------|--------|--------|------|------|
| Agent 记忆系统 | ✅ | ✅ | ✅ | ✅ | ✅ | 🟢 |
| SEARCH-R 方法论 | ✅ | ✅ | ✅ | ✅ | ✅ | 🟢 |
| 上下文管理策略 | 🔴 | ✅ | 🟡 | 🟡 | 🟡 | 🟡 |

## 枢纽节点分析

| 课题 | 连接数 | 角色 | 说明 |
|------|--------|------|------|
| Agent 记忆系统 | 3 | 枢纽 | 连接了上下文管理、SEARCH-R、质量门控 |

## 孤岛课题

无

## 建议行动

1. **[高优先级]** 恢复上下文管理策略课题，利用记忆系统的 Insight
2. **[中优先级]** 深入研究跨域洞察"层间同步策略"
3. **[低优先级]** 在下次 SEARCH-R 梳理时重点关注 Agent 记忆系统的枢纽作用

## 下次梳理

- 计划日期：2026-08-28
- 重点关注：上下文管理策略的恢复进展
```
